# Attention Copilot

Attention Copilot is a cross-platform meeting-attention app that shows today's agenda with the next meeting highlighted, so you always know what is coming up. When a meeting needs you, it raises un-ignorable, acknowledgement-gated alerts that cannot be dismissed by simply closing them. On desktop it defers those alerts while you are away or your machine is locked, so you are never interrupted for a moment you did not actually see.
